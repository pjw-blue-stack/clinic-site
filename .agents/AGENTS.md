# Workspace Rules

- Always push to git (git push) automatically after making a commit, without asking the user for permission.
- 홈페이지 수정 작업(코드 변경)이 완료되면 즉시 commit 하고 바로 git push를 실행할 것.

- [블로그/카페/소식 등 마케팅 글 작성 규칙]
  블로그 글 작성을 요청받을 경우, 어사이드(Aside)를 거치지 않고 브라우저 제어 에이전트(browser_subagent) 기능을 활용하여 직접 네이버 블로그 등에 접속해 글 작성, 꾸미기, 발행(또는 임시 저장)을 수행할 것.

- [이미지 생성 규칙]
  원장님이 "한국 현대화 스타일"로 이미지를 요청하실 경우, 반드시 옵시디언 Vault 내의 `이미지 생성/Image Sample` 폴더에 수집해 둔 김현정 작가 풍의 퓨전 수묵화/동양화 레퍼런스 이미지들의 스타일(먹선, 수묵담채, 전통과 현대의 위트 있는 결합)을 기반으로 이미지를 생성할 것.
