# Workspace Rules

- Always push to git (git push) automatically after making a commit, without asking the user for permission.
- 홈페이지 수정 작업(코드 변경)이 완료되면 즉시 commit 하고 바로 git push를 실행할 것.

- [블로그/카페/소식 등 마케팅 글 작성 규칙]
  원장님께서 여러 개의 글(예: 7개의 포스팅) 작성을 요청하실 경우, '어사이드(Aside) 브라우저'에 한 번에 복사해서 붙여넣을 수 있도록 아래와 같은 포맷을 준수하여 작성할 것:
  1. 최상단에 **[어사이드(Aside) 동작 지시서]**를 배치하고, AI가 순서대로 각 플랫폼에 업로드(예약 발행 등)해야 한다는 명확한 프롬프트를 포함할 것.
  2. 각 포스팅 사이에는 `==============================` 와 같은 명확한 구분선을 삽입할 것.
  3. 각 포스팅의 시작 부분에 `**[포스팅 N - 요일/플랫폼]**` 형태의 제목을 달아 AI가 시각적으로 완벽하게 구별할 수 있도록 할 것.
